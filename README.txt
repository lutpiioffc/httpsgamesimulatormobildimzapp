REAL CAR SIMULATOR INDONESIA
============================
Cara main:
1. Ekstrak ZIP, buka index.html di Chrome (HP/PC). Bila file:// tidak jalan, upload folder ke
   hosting statis gratis (Netlify Drop / GitHub Pages) lalu buka link-nya.
2. Three.js dimuat otomatis dari CDN (butuh internet saat pertama dibuka). Untuk 100% offline,
   unduh three.min.js r128 dan simpan sebagai libs/three.min.js.
Kontrol HP: Gas, Rem, Mundur, panah kiri/kanan, Klakson, Kamera, Lampu, Siang/Malam.
Keyboard: W/S/A/D atau panah, Spasi rem, C kamera, H klakson, L lampu, N siang/malam, Esc menu.
